Nepal Government Officials Data

This project began while searching for agricultural officials across Nepal and finding out who worked where. Public staff pages linked from municipality and rural-municipality URL lists are collected here to make those listings easier to explore.

The table shows 100 records per page. Use the filters to narrow the full dataset by province and district.

Data was extracted in March 2025. This is a point-in-time compilation of public source pages, not an official government publication. Records may have changed since extraction, and some source links may no longer work. When available, use each row's source link to check the original listing.
